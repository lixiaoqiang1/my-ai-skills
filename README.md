# my-ai-skills

只管理**自己创建或下载**的 Agent Skills。

```
common/      自用技能
yuanxingtu/  下载/专题技能
```

Cursor / Codex 自带技能在各自目录，不进本仓库：

- Cursor 内置：`~\.cursor\skills-cursor`
- Codex 系统：`~\.codex\skills\.system`

联接与新增规范见 [add-codex-link.md](add-codex-link.md)；完整技能树见 [SKILLS.md](SKILLS.md)。

- `~\.cursor\skills` → `F:\my-ai-skills`
- `~\.codex\skills\<技能名>` → `common\` 或 `yuanxingtu\` 下对应目录
