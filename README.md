# my-ai-skills

只管理**自己创建或下载**的 Agent Skills。

Cursor / Codex 自带技能分别在各自目录，不放进本仓库：

- Cursor 内置：`~\.cursor\skills-cursor`
- Codex 系统：`~\.codex\skills\.system`

本仓库通过联接给两边用：

- `~\.cursor\skills` → `F:\my-ai-skills`
- `~\.codex\skills\<技能名>` → `F:\my-ai-skills\<技能名>`（见 [add-codex-link.md](add-codex-link.md)）
